
部分住宅IP产品可能存在流量套餐。

例如：

* 每月固定流量
* 按流量计费
* 无限流量但限制带宽
* 固定带宽但限制并发

因此需要根据实际业务计算每月使用量。

### 查看售后规则

长期住宅IP并不是购买完成就结束。

如果出现：

* IP无法连接
* IP被运营商回收

* IP归属发生变化

需要知道服务商是否提供更换、检测或技术支持。
